TinyFish Browser Core (simulation)

Static single-page demo of an agentic-browser control room. Includes goal presets, a mock DOM viewport, simulated state-machine logs, JSON/Markdown output, JSON download, cURL example, mock Identity Vault, and a human-approval pause for sensitive actions.

Run locally by opening index.html. No build step or API key is needed.

Limitations: this is not TinyFish or a real browser automation engine. Pages, offers, logs and extracted fields are synthetic. No live browsing, remote browser, SSE backend, checkout or booking is connected. Identity Vault is mock UI; never enter real secrets. Webhook endpoint is a placeholder.

Free hosting: GitHub Pages can host this static frontend. Configure Pages to deploy from the feature/tinyfish-browser-core branch and publish this folder if your Pages settings allow it, or copy the folder contents to the configured Pages root. Existing Android project files are not overwritten.
